# LTmetric LENZ LiDAR

LENZ LiDAR는 LiDAR 점군을 3D로 열람하는 Windows용 뷰어입니다. COPC 파일을 열어 좌표와 점 속성을 확인하고, LAS·LAZ 파일을 COPC로 변환할 수 있습니다.

## 다운로드 및 실행

1. [GitHub 릴리스](https://github.com/LTmetric/LENZ_LiDAR/releases)에서 **Assets**의 `LTmetric-LENZ-LiDAR-v1.0.zip`을 다운로드합니다.
2. ZIP을 원하는 폴더에 압축 해제합니다.
3. `LTmetric-LENZ-LiDAR.exe`를 실행합니다.

`Source code (zip)`은 GitHub에서 자동으로 생성하는 저장소 압축 파일입니다. 프로그램을 실행하려면 위에 안내한 배포 ZIP을 받으세요.

## 라이선스

제품 이용조건은 배포 ZIP의 `LICENSE.txt`에서, 제3자 라이선스와 고지는 `licenses` 폴더에서 확인할 수 있습니다.
